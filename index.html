  • ( FICHA DO PROJETO · 2026 )

    GrowAI

    Horta semi-hidropônica inteligente com IA · TCC

    TCC do Técnico em Informática · UNASP – São PauloEm equipeIoT/RobóticaWeb

    Título científicoSistema IoT semi-hidropônico inteligente para modulação de princípios ativos em plantas medicinais

    O problema

    A concentração de princípios ativos em plantas medicinais depende diretamente das condições de cultivo, como temperatura, umidade e irrigação. Acompanhar tudo isso à mão é trabalhoso e pouco preciso.

    A solução

    Um sistema IoT completo que acompanha o cultivo em tempo real, com sensores de temperatura e umidade do solo e imagens da planta pela ESP32-CAM, e aciona a irrigação automaticamente. Os dados chegam a um site e a um app com painel, câmera, estações de cultivo e relatórios.

    Minha participação

    Fui responsável pela parte física do sistema: montei a estrutura hidráulica e integrei toda a eletrônica (ESP32, sensores, módulo relé e bomba d’água). Também contribuí no site e criei o Endosymbiosis Protocol, jogo que leva o tema do projeto para uma experiência interativa.

    Tecnologias

    • ESP32
    • ESP32-CAM
    • Sensor de temperatura
    • Sensor de umidade do solo
    • Módulo relé
    • Bomba d’água
    • HTML
    • CSS
    • JavaScript
    • Python (IA)

    Resultado

    Nota máxima na avaliação final. Apresentado na Tech Week 2026 e, em formato de pôster, no III Simpósio de Pré-Iniciação Científica (SIPIC) da UNASP-SP. O artigo está em processo de publicação.

    Endosymbiosis Protocol

    Jogo de terror point-and-click para navegador

    Parte do TCC GrowAIIndividualJogos

    O projeto

    Um jogo de terror point-and-click criado para o TCC GrowAI. O jogador avança pela história explorando cenas e interagindo com cliques, direto no navegador, sem precisar instalar nada.

    Minha participação

    Projeto individual, feito de ponta a ponta: escrevi o roteiro, construí toda a lógica do jogo no sistema de eventos do GDevelop, criei a ambientação de terror e desenvolvi e publiquei o site do jogo.

    Destaques

    • Roda em qualquer navegador, sem instalação
    • Site próprio publicado na Vercel
    • Leva o tema do GrowAI para uma experiência interativa

    Tecnologias

    • GDevelop (sistema de eventos)
    • HTML
    • CSS
    • JavaScript
    • Vercel

    Resultado

    Jogo publicado e disponível online, integrado ao projeto GrowAI.

  • ( FICHA DO PROJETO · 2025 )

    GeoImpacto

    Site educativo sobre desastres naturais

    Projeto Edutec 2025Em equipe · 6 integrantesWeb

    O problema

    Tornar o estudo de desastres naturais mais envolvente para estudantes, trocando a leitura passiva por uma experiência interativa e competitiva.

    A solução

    Um site completo com páginas sobre furacões, terremotos, tsunamis, incêndios, enchentes e erupções vulcânicas, uma linha do tempo histórica e o quiz Natural Disaster Survivor. Cada jogador cria a própria conta, acompanha o histórico de pontuações e disputa o pódio público com os 3 melhores, exibido logo na página inicial.

    Destaques

    • Front-end em JavaScript puro, sem dependências nem etapa de build
    • Design system próprio e componentes reutilizáveis
    • API própria em Node.js + Express conectada a um banco PostgreSQL
    • Telas de carregamento e de erro com opção de tentar de novo
    • Login seguro: o navegador guarda só o id e o nome, nunca a senha

    Tecnologias

    • HTML
    • CSS
    • JavaScript
    • Node.js + Express (API)
    • PostgreSQL (Neon)
    • Vercel

    Resultado

    Desenvolvido para o Edutec 2025 e apresentado na Tech Week 2025. Site e API publicados e funcionando online.
